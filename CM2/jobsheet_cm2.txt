2. Praktikum
    Waktu Pengerjaan : 200 menit

    Instruksi Pengerjaan:
    Setiap mahasiswa membuat kode program berdasarkan studi kasus yang telah diberikan.
    Pastikan program berjalan dengan baik, mengimplementasikan semua fitur yang diminta,
    dan dinamis (menggunakan menu untuk memilih fitur).
    Soal Studi Kasus:
    Pada jam makan siang, resto Royal Delish memiliki banyak pelanggan yang datang secara
    bersamaan.
    Kasir mengalami kesulitan mencatat antrean pembeli dan pesanan makanan karena
    proses masih dilakukan secara manual.
    Akibatnya:
        • Nomor antrean sering tertukar.
        • Data pembeli tidak tercatat dengan rapi.
        • Pesanan makanan sulit direkap.
    Untuk mengatasi masalah tersebut, dibuatlah sistem informasi antrean berbasis Linked
    List/Double Linked List.
    Alur sistem:
        • Pembeli datang dan mengambil nomor antrean.
        • Data pembeli dimasukkan ke sistem.
        • Ketika dipanggil, pembeli melakukan pemesanan makanan.
        • Data pesanan disimpan.
        • Sistem dapat menampilkan laporan pesanan dan total pendapatan restoran.

Ketentuan Tambahan
Program tidak boleh menggunakan Collection Framework seperti:
   • ArrayList
   • LinkedList
   • Queue
   • Stack
   • Collections.sort()
   • Sorting dilakukan secara manual.
Program wajib menggunakan object dan konstruktor.
Penggunaan Double Linked List pada kedua struktur data akan memperoleh nilai maksimal
pada aspek struktur data.
